# VP Truck Survivors

Играбельный HTML5-прототип Brotato-like для Telegram Mini App.

## Что внутри

- Главный герой: грузовик доставки с `vp`-бейджем на кузове.
- Противники: легкие, быстрые, грузовые, щитовые дроны и отдельные боссы.
- 3 вариации грузовика:
  - VP Магистраль: больше HP, стартовая автотурель.
  - VP Экспресс: быстрее, стартовые боковые рейки.
  - VP Бронеборт: больше брони, стартовая EMP-катушка.
- 2 локации:
  - Складской двор с воротами, контейнерами, паллетами, погрузчиками, лужами, световыми мачтами и док-зоной.
  - Лесная трасса с разметкой, КПП, знаками, деревьями, камнями, обочинами и дорожными деталями.
- Волны закрываются по количеству убийств, а не по таймеру.
- На каждой третьей волне после обычной квоты появляется босс.
- Боссы: дрон-надзиратель, щитовой крейсер, матка роя и красный перехватчик.
- Детали за уничтожение дронов, бонус за босс-волну, сервис-апгрейды между волнами.
- Детальная статистика забега: время, волны, урон, выстрелы, детали, боссы, топ целей, апгрейды и дистанция.
- Растровый 2D/2.5D art pass: сгенерированные игровые фоны для двух карт, PNG-спрайты грузовиков и дронов, мягкие тени, световые оверлеи, следы шин, выхлоп, опасные зоны атак, boss HP bar и экранная тряска.
- Ассеты лежат в `assets/`: `map-yard.png`, `map-road.png`, `truck-*.png`, `drone-*.png`.

## Как открыть

Откройте `index.html` в браузере. Прототип не требует сборки.

## Устройство игры

- `index.html` содержит canvas, HUD, экран выбора, сервис-апгрейды и финальный экран.
- `styles.css` отвечает за HUD, модальные панели, финальную статистику и мобильную адаптацию.
- `game.js` держит весь игровой цикл: `state` для текущего забега, `player` для грузовика, массивы врагов/снарядов/эффектов.
- Волны идут по квоте убийств: `getWaveKillGoal`, `updateSpawning`, `spawnBoss`, `killEnemy`.
- Оружие считается в `updateWeapons`, урон проходит через `damageEnemy`, урон игроку через `damagePlayer`.
- Статистика забега хранится отдельно в `runStats`, выводится через `renderFinalStats` и отправляется в Telegram через `buildResultPayload`.

## Как подключить к Telegram

1. Разместить папку на HTTPS-хостинге.
2. В боте отправлять кнопку `web_app` с URL на `index.html`.
3. При нажатии "Отправить результат" Mini App вызовет `Telegram.WebApp.sendData(...)`.
4. На стороне бота обработать JSON. Payload отправляется как отдельный результат этой игры:

```json
{
  "type": "vp_truck_survivors_result",
  "event": "complete",
  "progress": 100,
  "game": "vp_truck_survivors",
  "score": 1200,
  "wave": 4,
  "kills": 96,
  "truck": "long",
  "truckName": "VP Магистраль",
  "location": "yard",
  "locationName": "Складской двор",
  "stats": {
    "duration": "3:42",
    "durationSeconds": 222,
    "damageDealt": 8400,
    "damageTaken": 87,
    "shotsFired": 340,
    "coinsEarned": 168,
    "coinsSpent": 52,
    "bossesKilled": 1,
    "killsByType": {
      "scout": 54,
      "sting": 21,
      "carrier": 16,
      "shield": 5
    }
  }
}
```

`vp`-надпись в прототипе нарисована как плейсхолдер. Для продакшена лучше заменить ее на согласованный брендовый ассет.
